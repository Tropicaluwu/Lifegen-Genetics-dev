## Skills

LifeGen adds additional skills, the most recent addition being the Gardener skill! All of these are used quite frequently in flavor text, and there are future plans on adding game influences as well.

"Skill name" is the code name for the skill. The tiers determine how good the cat is in their skill, and what text is shown on the cats profile. The numbers next to each tier is the range of the skill tier. 

"Interest skill" is used for kittens and adolescents.
